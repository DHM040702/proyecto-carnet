## 📌 Descripción general

El *Sistema de Emisión de Carné Universitario* es una aplicación diseñada para *gestionar, registrar y controlar* la emisión de carnés de identificación para estudiantes universitarios.

Permite administrar de forma *eficiente, segura y trazable* la información del estudiante, validar su condición académica y generar el carné universitario de manera ordenada.

Este sistema está orientado a *instituciones de educación superior* que buscan modernizar y optimizar el proceso de emisión del carné universitario.

---

## 🎯 Objetivos del sistema

- ✅ Automatizar el proceso de emisión del carné universitario  
- ✅ Garantizar la correcta identificación de los estudiantes  
- ✅ Mantener la trazabilidad de los carnés emitidos  
- ✅ Reducir errores y tiempos en el proceso administrativo  
- ✅ Facilitar la gestión y control por parte de las oficinas responsables  

---

## ⚙️ Funcionalidades principales

- 👨‍🎓 Registro y validación de estudiantes  
- 🪪 Emisión de carné universitario  
- 🔄 Renovación y anulación de carnés  
- 🗂️ Gestión de datos académicos básicos  
- 📊 Generación de reportes de carnés emitidos  
- 🔍 Búsqueda y consulta de carnés por estudiante  
- 🔐 Control de acceso por roles

## 🚀 Instalación básica

``` bash
# 1. Clonar el repositorio
git clone <URL_DEL_REPOSITORIO>

# 2. Ingresar al proyecto
cd nombre-del-proyecto

# 3. Configurar variables de entorno
cp .env.example .env

# 4. Instalar dependencias
composer install
npm install

# 5. Configurar base de datos y ejecutar migraciones
php artisan migrate

# 6. Iniciar servidor
php artisan serve
npm run dev


```
